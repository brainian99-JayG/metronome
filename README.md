# 메트로놈 (광고 없는 개인·가족용 PWA)

스마트폰 홈 화면에 설치해서 쓰는 메트로놈입니다. 광고 없음, 인터넷 없이 동작, 앱 용량 약 60KB.

**배포 주소: https://brainian99-jayg.github.io/metronome/**  
저장소: https://github.com/brainian99-JayG/metronome  (GitHub Pages, `main` / root)

## 기능
- BPM 30~300 (−/+ 버튼은 **길게 누르면 연속 증감**, 슬라이더, TAP 입력)
- 박자표: 1/4, 2/4, 3/4, 4/4, 5/4, 6/8, 9/8, 12/8 (강박·중강박 자동 강세)
- 분할음: 기본 / 8분 / 3연음 / 16분
- 비트 시각 표시등, 빠르기말 표시(Allegro 등)
- 소리 크기, 진동(안드로이드), 재생 중 화면 켜짐 유지, 첫박 강조 On/Off
- 마지막 설정 자동 저장 · 오프라인 실행
- PC에서는 스페이스바(재생/정지), ↑↓(BPM ±1)

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구성 + 디자인 |
| `app.js` | 메트로놈 엔진(정밀 스케줄러), 조작 로직 |
| `sw.js` | 오프라인 캐시(서비스 워커) |
| `manifest.webmanifest` | 앱 이름·아이콘·전체화면 설정 |
| `icons/` | 앱 아이콘 (192·512·마스커블·iOS용) |
| `make_icons.py` | 아이콘 재생성용 스크립트 (`python make_icons.py`) |

> `KakaoTalk_*.jpg` 는 참고용 샘플 캡처라 배포에 포함하지 않아도 됩니다.

## 1. PC에서 먼저 확인하기

이 폴더에서 아래 명령을 실행한 뒤, 크롬에서 `http://127.0.0.1:8123` 접속.

```bash
python -m http.server 8123
```

같은 와이파이의 폰에서 미리 보려면 위 명령을 실행한 채로 PC의 내부 IP(`ipconfig` 로 확인, 예 `192.168.0.5`)를 써서 폰 브라우저에 `http://192.168.0.5:8123` 을 입력합니다.
※ 이 방식은 `http` 라서 **"홈 화면에 추가"와 오프라인 기능은 동작하지 않습니다.** 소리·조작 확인용입니다. 정식 설치는 2번 방법으로 하세요.

## 2. 배포 — GitHub Pages (무료, 가족에게 링크만 보내면 끝)

한 번만 해두면 이후에는 링크 공유만 하면 됩니다.

1. https://github.com 에서 무료 계정 생성 (가입비 없음)
2. 우측 상단 **＋ → New repository**
   - Repository name: `metronome`
   - **Public** 선택 (Private 이면 Pages 무료 사용 불가)
   - **Create repository**
3. 생성된 화면에서 **uploading an existing file** 링크 클릭
   → 이 폴더의 `index.html`, `app.js`, `sw.js`, `manifest.webmanifest` 와 **`icons` 폴더**를 통째로 끌어다 놓기 → **Commit changes**
   (명령어 사용 없이 브라우저 드래그만으로 됩니다)
4. 저장소 상단 **Settings → 좌측 Pages**
   - Source: **Deploy from a branch**
   - Branch: **main** / 폴더: **/ (root)** → **Save**
5. 1~2분 뒤 같은 화면에 주소가 표시됩니다:
   `https://<내아이디>.github.io/metronome/`
6. 이 주소를 폰에서 열어 설치(3번 참고). **가족에게는 이 주소만 카톡으로 보내면 됩니다.**

---

## 3. 폰에 설치하기

### 안드로이드 (크롬)
1. 링크 접속 → 우측 상단 **⋮** → **홈 화면에 추가** (또는 하단에 뜨는 "설치" 안내 배너)
2. **설치** 확인 → 홈 화면에 아이콘 생성
3. 아이콘으로 실행하면 주소창 없는 전체화면 앱으로 열립니다.

### 안드로이드 (삼성 인터넷)
링크 접속 → 하단 **≡** → **현재 페이지 추가 → 홈 화면**

### 아이폰 (사파리 필수, 크롬은 불가)
1. **사파리**로 링크 접속 → 하단 가운데 **공유(↑)** 버튼
2. **홈 화면에 추가** → **추가**
3. 아이폰은 **측면 무음 스위치가 켜져 있으면 소리가 나지 않습니다.** 무음 해제 후 사용하세요.

설치 후에는 비행기 모드에서도 실행됩니다(첫 실행 시 한 번은 인터넷 필요).

## 4. 나중에 수정할 때

1. 파일을 고친다
2. **`sw.js` 첫 줄의 `metronome-v1` 을 `v2`, `v3` … 로 올린다** ← 이걸 해야 가족들 폰의 캐시가 갱신됩니다
3. GitHub 저장소에서 같은 파일을 다시 업로드(덮어쓰기) → 1~2분 뒤 반영
4. 폰에서는 앱을 껐다 다시 켜면 새 버전으로 바뀝니다

## 5. 알려진 제약 / 참고

- **백그라운드 재생 제한**: 홈 버튼으로 나가거나 화면을 끄면 소리가 멈출 수 있습니다(웹앱 공통). 앱을 켜 둔 채 연습하는 용도이며, 설정의 "화면 유지"가 켜져 있으면 재생 중 화면이 꺼지지 않습니다.
- 다른 앱을 보다 돌아오면 **밀린 박자를 몰아서 내지 않고 첫박부터 다시 맞춰** 이어집니다(의도된 동작).
- **진동**은 안드로이드에서만 동작합니다(iOS 미지원).
- **6/8·9/8·12/8**은 BPM 이 4분음표(♩) 기준이므로 8분음표가 그 절반 간격으로 울립니다. (예: ♩=84 → 8분음표 168회/분)
- 백그라운드 재생이 꼭 필요해지면, 이 폴더를 그대로 https://www.pwabuilder.com 에 넣어 APK로 변환해 설치할 수 있습니다.
